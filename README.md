# StudentTrack

## 👋 ¡Bienvenido/a a StudentTrack!

**StudentTrack** es una aplicación fácil de usar diseñada para **tutores y profesores**. Te ayuda a organizar y gestionar los datos de tus alumnos, especialmente cuando están en grupos o prácticas.

Es como una agenda digital para tus estudiantes y sus grupos.

## ✨ ¿Qué puedes hacer con StudentTrack?

Con esta aplicación, podrás:

* **Añadir nuevos alumnos** y guardar su información (nombre, apellidos, email, teléfono).
* **Ver y editar** los datos de tus alumnos.
* **Crear y organizar grupos** de trabajo.
* **Asignar alumnos a grupos**.
* **Ver los alumnos** que pertenecen a cada grupo o curso.
* **Actualizar y eliminar** tanto alumnos como grupos.
* Toda tu información se guarda de forma **privada y segura** en tu propio ordenador.

## 🚀 Cómo Empezar (¡Es muy fácil!)

StudentTrack no necesita una instalación complicada. Es una aplicación "portable", lo que significa que puedes usarla directamente.

### Para usuarios de Windows:

1.  **Descarga:** Baja el archivo `StudentTrack_Windows_x64.zip` desde la sección de descargas del proyecto (si la hay).
2.  **Descomprime:** Haz clic derecho sobre el archivo ZIP y elige "Extraer todo..." o "Descomprimir". Elige dónde quieres guardar la carpeta (por ejemplo, en "Mis Documentos" o en el Escritorio).
3.  **Ejecuta:** Abre la carpeta que acabas de descomprimir y haz doble clic en el archivo `StudentTrack.exe`. ¡La aplicación se abrirá!

### Para usuarios de Linux:

1.  **Descarga:** Baja el archivo `StudentTrack_Linux_x64.zip` desde la sección de descargas del proyecto (si la hay).
2.  **Descomprime:** Abre el archivo ZIP y extrae su contenido en la ubicación que prefieras (por ejemplo, en tu carpeta personal).
3.  **Prepara (si es necesario):** Abre una terminal, ve a la carpeta donde descomprimiste la aplicación y escribe este comando para darle permiso de ejecución:
    ```bash
    chmod +x StudentTrack
    ```
4.  **Ejecuta:** Ahora, desde la terminal en esa misma carpeta, escribe:
    ```bash
    ./StudentTrack
    ```
    O haz doble clic en el archivo `StudentTrack` directamente desde tu explorador de archivos.

La primera vez que la uses, la aplicación creará automáticamente una pequeña base de datos para ti dentro de la misma carpeta.

## 👨‍💻 Uso Básico de la Aplicación

1.  Al abrir la aplicación, verás las **secciones de cada curso** (ASIR, DAM, DAW).
2.  Debajo de cada curso, podrás **añadir nuevos grupos** haciendo clic en el botón `+ Grupo`.
3.  Haz clic en el **nombre de un grupo** para ver la lista de alumnos que contiene.
4.  Desde la vista de grupo, podrás **añadir nuevos alumnos** o hacer clic en un alumno para **ver sus detalles, editarlos o eliminarlo**.
5.  Puedes **editar o eliminar grupos** con los iconos que aparecen junto a su nombre.

¡Es así de sencillo! Explora la aplicación para familiarizarte con todas sus funciones.
